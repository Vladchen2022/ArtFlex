# ArtFlex 十项交互改进与界面验收

日期：2026-10-06。分支：`codex/interaction-workflows`。起点：`44b1ec2`。

## 决策与范围

保留顶部、左侧工具栏、中央画布和右侧面板的职责及位置。复用已有图层、蒙版、Metal 纹理填充、选区运算、文档保存、RasterExporter 和 HistoryController；参数、菜单、文件位置选择使用 SwiftUI / AppKit。没有引入新依赖，也没有改成 CPU 画布合成。

实施顺序为接入现有操作入口、补充预览草稿和提交／取消边界、加入原生菜单及参数记忆，然后用可见界面验证。修复时优先使用项目现有 GPU 复制和历史检查点；无需为这些交互另建渲染器或保存系统。

本轮十项内容：

| --- | --- |

没有以后台单元测试或脚本调用业务方法代替界面测试。通过 CUA 在可见的 `ArtFlex交互验收` 窗口操作原生按钮、菜单、文本框、滑块和画布，并读取窗口状态及截图。构建命令只用于编译。

## 发现并修复的问题

1. 原生画布抢走半径文本框焦点。补充原生输入拦截、文本输入焦点识别和独立数值草稿。
2. 画布外围的本地事件监听器将胶囊点击当作选区操作。预览期间卸载外围捕获；用真实控件边界排除胶囊点击；修正监听回调将应吞掉的 nil 事件重新传递的问题。业务入口同时拒绝预览期间的选区编辑。
3. 组合模式只影响选区计算，鼠标按下仍按普通模式移动已有选区。将持久的增减选模式纳入手势决策。
4. 纹理调整只保存稀疏纹理对象，替换图层资源后失去稀疏存储，导致取消／撤销为空。复用现有 GPU 复制保留独立基准；预览刷新渲染版本而不写入文档历史。
5. 预览期间菜单仍可能修改图层。统一禁用冲突命令、右侧编辑区和历史入口；保留取消调整的撤销行为。
6. 忙碌时排队的另存为可能退化成普通保存。另存为遇到录像／恢复写入忙碌时明确要求稍后重试，不排队成普通保存。
7. 导出预设中的自定义背景被恢复成当前画笔颜色。保留已存 RGBA 值，界面明确显示“已存颜色”；用户仍可主动切换到“当前颜色”。
8. 纹理历史动作显示为内部名称“drag”。补充“纹理填充”和“调整纹理填充”的显示名称。

### 事件分发修复参考

实际查阅 Apple [Cocoa Event Handling Guide — Monitoring Events](https://developer.apple.com/library/archive/documentation/Cocoa/Conceptual/EventOverview/MonitoringEvents/MonitoringEvents.html)。本地监听器在应用分发事件时执行，并通过返回原事件或 nil 决定是否继续分发。原实现采用 `self?.handleLocalEvent(event) ?? event`，将处理函数用于阻止分发的 nil 又替换回原事件；此外未排除覆盖在画布外围的胶囊区域。修复针对监听范围和分发结果，而非继续补选区消失后的恢复逻辑。

## 验收结果

| 项目 | 实际界面操作与结果 |
| --- | --- |
| 绘画受阻提示 | 锁定绘画层后落笔出现解锁／新建层提示；点击解锁后可绘画。隐藏层落笔出现显示提示，点击后恢复绘画。通过。 |
| 图层／蒙版目标 | 点击白色蒙版缩略图后画黑色笔触，原笔画形成缺口；点击内容缩略图后新笔触写入颜色层。保存重开后蒙版缺口仍在。通过。 |
| 选区预览 | 羽化半径由 16 改为 80，开关覆盖显示后取消／应用；扩展输入 999 时禁止提交；取消不多加历史。最后对矩形依次扩展 40、收缩 40，边界回到原位置。通过。 |
| 纹理调整 | 用户绘制有效曲线区域；尺寸、覆盖率、排列、换结果可操作。最终样本先改环形并取消，恢复流向原图；再次调整并应用，Cmd+Z 恢复原图，Shift+Cmd+Z 恢复环形。历史为 2/2，即填充一次、调整一次。通过。 |
| 另存为 | 原稿另存为分支；分支增加一条长笔触并保存，重开原稿仍只有两条旧笔触。取消另存为后普通保存仍关联原文件。通过。 |
| 上下文胶囊 | 从已有选区内部起笔增选，得到两个矩形的并集；减选得到内部孔洞；交集只留下重叠矩形。通过。 |
| 快照入口 | 单击快照 0→1；右侧箭头打开列表，进入快照对比，取消回到绘画。通过。 |
| 历史与保存点 | 保存后历史标记“上次保存”；预览从 9/9 到 7/9，取消恢复原状态和已保存标记；纹理取消／撤销／重做历史步数正确。最终 Release 中实际显示环形图案缩略图，以及“初始状态·上次保存”标记。通过。 |
| 导出与预设 | 保存 PNG 1024、300 DPI 预设，切换 JPEG 后恢复 PNG 参数。透明背景／可见内容边界预览正确，实际导出后用 macOS 预览打开并查看信息，确认 1024×654、300 DPI、sRGB；完整画布文件为 1024×1024。最终 Release 中保存黑底预设，将画笔改红后恢复预设，背景仍为黑色；主动选择“当前颜色”才变为红色。通过。 |
| 命令查找 | Shift+Cmd+P 搜索“羽化”，无选区时显示不可用原因；搜索“另存为”后出现原生保存面板；原生菜单入口可见。通过。 |
