## 验收发现与修正

1. 16 位新建仍显示 8 位内存估算。容量策略、预设尺寸、创建检查和预览改为共享精度参数，16 位使用双倍工作集预算。
2. 裁剪模式下菜单 Return 可被画布截走。复用现有键盘入口，在 AppKit 菜单追踪期间暂停画布命令与抢回焦点。来源：[菜单开始追踪通知](https://developer.apple.com/documentation/appkit/nsmenu/didbegintrackingnotification)、[结束通知](https://developer.apple.com/documentation/appkit/nsmenu/didendtrackingnotification)。
3. 系统“文件”菜单打开后 CUA 界面访问再次失败，不能再据此推断用户锁屏。随后 Cmd+Q 的进程采样确认软件停在 `NSApplication _shouldTerminate` 的模态循环。旧代码返回 terminateLater 后等待 main queue 异步确认，这条调度可能无法前进。改为取消本次同步退出，在正常事件循环完成原有保存确认，再发起已批准退出；不绕过保存失败和取消保护。来源：[AppKit 退出流程与模态循环](https://developer.apple.com/documentation/appkit/nsapplication/terminate(_:))，采样 `/tmp/artflex-menu-access-sample.txt`。

菜单访问故障与退出等待是两条观察，不能声称一个修正已证明解决所有 CUA 菜单访问问题。新的退出调度会先取消系统当前请求，系统关机／注销时可能需要关闭 ArtFlex 后再次发起；本轮优先保证异步保存与正常应用退出可用，不声称已完成系统注销验收。

卡住的 23 实例只含独立测试稿。复制测试工程及恢复目录到 `~/Downloads/ArtFlex-核心升级屏幕验收-20260908-v4NTo2/` 后，向确认过的测试进程 49607 发送 SIGTERM，未删除工程。原画稿哈希未变。
