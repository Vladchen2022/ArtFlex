## 手测清单

每项只有实际结果符合预期才勾选。如果失败，记录所用工具/对象、操作前后截图，以及能否撤销。

已准备并打开独立验收工程：`/Users/victorcloux/Downloads/ArtFlex-体块参考验收-20260906.artflex`。其中包含方块、圆柱、圆环和可摆姿人体；构图收藏“验收构图”已锁定。需要删除或恢复快照时，先另存副本。优先验证取消、撤销、构图保护和保存重开，再验证设备手感。

### A. 放置与取消

- [ ] 新建并保存空白工程，进入“体块参考”。预期：仅进入工具不会出现未保存标记，也不会生成正式体块。
- [ ] 点击方块，在工作面单击。预期：出现一个默认大小方块，放置后回到选择，不会连续误建。
- [ ] 选择圆柱，先拖底面、松开，再拖高度。预期：两个阶段都有预览；完成后对象列表增加一个圆柱，轮廓与预览一致。
- [ ] 选择圆环或建筑模块，移动到画布。预期：先看到跟随光标的预览；点下才计入正式对象。按 Esc 后预览消失，再点画布不会意外放置。
- [ ] 创建底面或调整高度中按 Esc。预期：草稿完全消失，工程中不留下半成品。
- [ ] 开启“连续放置”，连续放置三个对象，再按 Esc。预期：三个独立对象，Esc 结束放置；关闭连续放置后恢复单次创建。

### B. 编辑、吸附与撤销

- [ ] 拖动方块到新位置，按 Cmd+Z，再重做。预期：一次撤销回到拖动前的位置，一次重做回到最终位置。
- [ ] 拖动移动轴、旋转环或缩放柄，拖动过程中按 Esc。预期：位置、角度、尺寸及模块基准点均恢复，不残留半次修改。
- [ ] 选择“移动 / 旋转 / 缩放”，输入数值并确认；再执行一次但按 Esc。预期：确认可撤销，取消不改变正式模型。
- [ ] 开启“拖面调尺寸”，拖方块一个面。预期：相对的面保持原位，只改变所拖方向；不能拉成负尺寸。旋转对象后重复，行为仍按对象的面方向。完成后关闭该开关恢复常规选择。
- [ ] 将旋转过的体块抬高，点击“落地”。预期：几何最低点落在地面，而不是对象中心落地；撤销恢复原高程。
- [ ] 拾取倾斜工作面后点“贴工作面”。预期：所选对象整体平移到工作面，不改变相对位置或旋转；无关自定义枢轴不移动。
- [ ] 展开“工作面与吸附”，开启格点/边点吸附，拖动时按住 Command。预期：普通拖动有吸附提示，Command 临时暂停；松开后恢复，工程里的吸附开关不被关闭。
- [ ] 选择圆柱或球体切换 8 / 24 / 32 段。预期：外形平滑程度改变，可撤销；旧工程未主动修改的对象保持旧分段。
- [ ] 放置可摆姿人体，改变两处关节，选中其中一处并点“复位该关节”。预期：只复位该关节，其他姿势保留，可撤销。

### C. 相机与构图保护

- [ ] 在“定视角”依次选择环绕、平移、远近并拖动画布。预期：只改变 3D 相机，绘画图层及画布缩放不跟随变形。
- [ ] 使用 Option 拖动、Option+Shift 拖动；有触控板时测试双指平移和捏合。预期：分别环绕、平移、远近；没有中键也能操作。
- [ ] 使用正面、侧面、顶面、斜视、对准所选和显示全部。预期：对象可找回，方向明确；撤销可返回前一相机状态。
- [ ] 收藏当前构图，修改名称，换视角后点击缩略图。预期：准确返回收藏视角。锁定收藏后不能覆盖、改名或删除；解锁后恢复操作。覆盖前需要确认。
- [ ] 点“临时环绕检查”，改变视角，再点“返回原构图”。预期：相机完全恢复，检查本身不改变工程中的正式构图。
- [ ] 点“锁定参考，返回绘画”，再点“返回体块编辑”。预期：再次进入仍保持锁定，建模控件不可误改；只有点击“解锁并编辑体块”才允许继续修改。

### D. 绘画参考与保存

- [ ] 在绘画界面的参考条隐藏/显示参考，调透明度并切换样式。预期：绘画像素不变，参考能找回；不会因为隐藏而删除场景。
- [ ] 设置不同的建模透明度和绘画透明度，往返两种模式。预期：各自记忆，不再用一只滑块同时干扰两种用途。
- [ ] 在“绘画参考”切换结构线、灰模、半透明叠看，展开简单光向并调整。预期：结构清楚、明暗方向变化；不需要材质编辑。
- [ ] 保存场景快照，修改模型/工作面/显示/相机/模块，再恢复。预期：完整恢复，模块仍能按关联选择和编辑；恢复操作可以撤销。
- [ ] 保存满六个快照后再保存。预期：提示已满，最早快照不会被悄悄挤掉；指定“替换”需确认。
- [ ] 保存工程，打开另一张空白工程，再重新打开该工程。预期：模型、曲面质量、人体姿势、构图收藏、显示设置和快照一致；空白工程没有上一张的临时预览。
- [ ] 在透视匹配中画过短或近乎平行的约束线。预期：给出不稳定提示，不能仅因为两条线相交就报告高可靠度。

### E. 流畅度与旧功能

- [ ] 使用 20、100、300 个简单体块的独立测试场景，环绕、选择、撤销。预期：没有卡死、崩溃、残留预览；大型场景可比小场景慢，但不应让界面长时间失去响应。
- [ ] 回归原有复制、分组/解组、镜像、阵列、测量、保存自定义模块和布尔操作。预期：入口仍存在，结果与旧工作流一致；高级功能没有因精简标签被删除。
