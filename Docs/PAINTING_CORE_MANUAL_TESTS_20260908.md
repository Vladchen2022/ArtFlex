# 绘画核心升级手测清单

候选构建 `20260908.23`。**目前尚未安装／完成屏幕验收，不要按旧版界面判定新实现。**以下在独立测试工程中执行，保留原画稿，不使用强制退出或磁盘写满测试。

## 1. 新建与高精度

- 新建 2048×2048，颜色精度选“16 位浮点”，创建按钮和精度说明应完整可见。
- 使用现有普通笔刷、认可的蜡笔／组合笔刷，由轻到重画，重复叠加、橡皮及涂抹正常；不能因高精度变得特别淡或改变纹理构成。
- 画平滑渐变，用吸管沿渐变取色，选区填充该颜色；满不透明处应与所选颜色相符，不额外变亮。数位板压力请分别用鼠标和实际压感笔验证。
- 保存为独立工程、关闭并重开，画面、图层、透明区域和精度选择应对应原工程；不出现彩色乱码或全黑。

## 2. 导出

- PNG 和 TIFF 选择 16 位，分别导出原尺寸及 50% 尺寸，再导入独立 16 位工程；透明边缘、颜色与构图应一致。
- JPEG 只允许 8 位，切换格式后不保留误导性的 16 位选项；取消导出不改变工程未保存状态。
- 在 8 位工程继续普通绘画、PNG 导出与打开，既有工程正常，不被自动升级成高精度。

## 3. 保留裁剪像素

- 在画布四角和中间各画不同颜色标记。选裁剪，保留中间部分并应用，四角暂不可见。
- 在裁剪后的画布新增笔触，再擦掉中间的一块。点“展开保留区域”，四角应回来，新笔触还在，刚擦掉的区域不能复活。
- 再裁剪、保存、重开后展开，结果一致；不依赖仍在内存中的撤销历史。
- 裁剪后复制图层，展开后副本也有四角；删除副本不影响原图层。撤销／重做复制与删除正常。
- 裁剪后给图层新增隐藏全部蒙版，展开后框内外都隐藏；反相后框内外都显示。删除蒙版不留下框外残余遮挡。
- 用两个不同颜色／不透明度的图层，在裁剪后向下合并或合并可见，再展开。框内外合成一致，不出现旧图层残片或接缝；撤销恢复两个图层。

## 4. 方案共享底稿

- 建立两个方案。在 A 中画、擦、改蒙版，切到 B，B 原画面必须不变。
- 连续画至少三笔后再切换，避免只验证第一次分离。回到 A，笔触全部保留。
- A 裁剪、展开或删除图层不能改变 B。应用／取消方案仍按原工作流处理，保存重开主画稿结果正确。

## 5. 大画布和恢复

- 新建 4096×4096，逐个增加空白图层并画局部笔触。观察是否出现丢笔、黑块、边缘截断；缩放、切层、撤销重做正常。
- 活动监视器观察内存趋势。空白层与局部绘画的已提交存储应更节省，但画笔工作纹理和历史仍占内存，不要求整机内存立即下降固定百分比。
- 在独立工程连续画几笔，停笔超过正常自动恢复间隔（约 30 秒）。再画一小块，等待下一代恢复；恢复入口中选择对应测试稿，最新已恢复笔触完整。不要用原画稿做覆盖实验。
- 保存／导出／切换工程时取消文件面板，当前内容应原样保留；保存失败仍显示未保存。故障注入和旧代删除独立性已由临时目录自动测试，不要求你手动删除恢复文件。
