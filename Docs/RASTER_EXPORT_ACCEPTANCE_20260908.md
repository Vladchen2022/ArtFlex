# 图片导出独立优化与界面验收

日期：2026-09-08。最终构建号：`20260908.12`。
本轮只完成图片导出模块，不代表整体优化方案已全部完成。

## 1. 决策摘要

- 仓库复用：沿用 `RasterExporter` 的 PNG/JPEG/TIFF 编码、线性预乘颜色转换、vImage 缩放、原子写入和 768 MiB 预计工作集预算；复用正式 Metal 图层合成、图层读回与异步文件面板包装。
- 官方方案：用 AppKit 异步附属文件面板。Apple 明确说明，向已有附属窗口的父窗口再添加 sheet 会排队；因此导出位置面板挂到当前导出设置窗口。回调先将文件面板移出屏幕。
- 选择：把 GPU 读回及编码放到后台，将现有预算校验提前到界面，不新建导出引擎、不增加依赖、不修改颜色编码和画笔公式。
- 本轮没有重写工程保存、旧内部 PNG 快捷方法、快照批量导出或方案批量导出。

## 2. 实施顺序

1. 核对已完成模块，选定图片导出；备份六个源码文件与上一版应用。
2. 修复导出位置窗口生命周期、边界状态和后台读回。
3. 将尺寸与内存预算接入导出前校验，错误直接显示在窗口里。
4. 构建 `.11`，在独立工程上通过界面导出并用 Finder 快速查看。
5. 实测发现 JPEG 质量控件需要额外滚动；扩大参数区，加入边界说明，构建 `.12` 并复测。
6. 完成 TIFF 同名替换，重新打开原画稿，核对文件未变后停止。

## 3. 代码改动

- 位置选择不再调用 `runModal`。从选择位置开始标记忙碌，防止重复发起、切换工程或退出打断导出。取消位置选择后仍留在原设置窗口，参数不丢失，可立即重试。
- 导出设置的可见内容检测明确区分计算中、空内容、失败；请求 ID、文档 ID 与修订检查防止关闭/重开后的旧检测结果写回。
- 空透明画布选择可见边界时直接提示没有内容并禁用导出，不再无限显示正在计算。
- 与录像共用正式可见图层合成入口，并包含最近仍处于可调整实时缓冲中的笔触。导出图片不再仅为取得最新像素而强制提交绘画历史。
- 主线程只准备独立的 Metal 合成目标；GPU 读回、可见范围扫描、裁切、缩放、编码和原子写入在后台任务完成。仍存在主线程合成准备成本，不宣称整个入口完全无主线程工作。
- 界面和正式编码复用同一套尺寸及预计内存预算校验。超限在选择路径与分配读回前提示，编码阶段仍再次校验。
- 修正裁切区域相加可能整数溢出的校验方式，并在浮点尺寸转整数前检查四舍五入后的边界。
- 导出窗口显示持久错误；统一深色配色，扩大参数滚动区；补充 DPI 不增加像素、指定宽高可能改变比例、背景图层参与可见边界的说明。
- 保留已有原子写入机制，不把它列为本轮新发明的能力。

## 7. 用户手测清单

请使用工程副本。

1. 点击导出，输入一个较小宽度，检查输出高度是否按比例变化；打开位置面板再取消，参数应保留，重新点击应能导出。
2. 输入宽度 100000 或 20000，分别确认边长/内存预算警告与禁用按钮；改回 800 应恢复可用。DPI 输入 0 应被拦住。
3. 在含蒙版的图层上画最后一笔，不保存，直接导出 PNG 或 JPEG；打开结果，检查最新笔触、蒙版、颜色与方向。
4. 隐藏不透明背景图层，选择“可见内容边界”和“透明”，导出 PNG/TIFF；检查裁切后的尺寸和透明背景。若整个画布仍是不透明的，边界不会缩小。
5. 在空透明画布选择可见内容边界，应提示没有可见内容；完整画布导出仍可选。
6. 导出 TIFF 后改变尺寸，再选同名测试文件，确认系统询问替换；确认后重新打开，检查新尺寸和可读性。

## 8. 风险与未覆盖项

- 没有导出速度前后基准、最大画布长时间压力测试、内存峰值记录或真实打印色差测试。
- 没有注入磁盘写满、权限变化、GPU 命令失败、编码器故障或进程中断。失败显示和退出保护已实现，但这些异常路径未全部通过界面故障验证。
- 编码/写入开始后不提供强制中止，避免把取消与目标文件安装混在一起；可以在位置面板取消。没有宣称支持“写入中立即取消”。
- 原子写入沿用 Foundation `Data.write(.atomic)`，不等价于保证所有文件系统和断电情形下永久落盘。
- GPU 合成准备仍在主线程，未全面重构底层 GPU 错误传播；不能据此宣称整个应用任意 GPU 故障下都安全。
- 本轮测试没有覆盖精确宽高、当前颜色背景、所有 ICC 来源和极小窗口；保留现有实现，仅补充了提示及通用校验。
- 单次保存面板意外退回仍存在来源不确定性；后续多次 PNG/TIFF 保存、取消和替换均完成，仍建议用户实际工作时复核导出文件。
- 本轮到此停止，下一部分等待用户确认。
