# 纹理填充当前状态

## 产品行为

`纹理填充 / textureFill` 位于原“基底填充”工具位置，默认快捷键为 `F`，可在设置页修改。

操作流程：

1. 选择纹理填充。
2. 用压感笔在画布上圈出闭合区域。
3. 松开后，工具在该区域内一次性生成纹理。

拖动阶段只更新选区轮廓，不改写图层像素；提交后产生一条可撤销历史记录。

## 素材来源

- 默认使用当前绘画画笔生成材质场。
- 可从共享笔尖图片库选择导入素材。
- 填充开始时冻结画笔、颜色、素材和参数，操作过程中切换画笔不会改变本次结果。

## 参数

- `纹理尺寸`：控制材质在画布中的尺度。
- `排列`：提供流向、交织、环形、散布四种空间排列；流向模式保持旧工程行为。
- `覆盖率`：控制区域内保留纹理的密度。
- `变化度`：控制方向扰动、低频密度变化和二次材质采样。
- 覆盖率在 65% 以上、变化度在 55% 以上进入增强尾段；滑块拉满时覆盖率响应为 2 倍、变化度响应为 4 倍，默认 58% / 45% 不变。
- 覆盖率阈值在标准 100% 处封顶，额外增强只提高纹理密度，避免最大值退化成整块实色。
- 颜色和透明度继续使用当前颜色、画笔不透明度和顶部不透明度链路。
- 参数面板提供结果预览，使用与正式提交相同的 `SelectionFillRenderer`；拖动滑块时局部更新预览，松手后提交参数。
- 预览使用固定 seed 和固定方向，便于比较参数。正式填充仍按每次操作 seed 和套索主轴生成，因此分布不会逐像素一致。

## 实现边界

- 选区遮罩继续使用现有闭合套索栅格化流程。
- 当前画笔通过 `StageOneBrushPreviewRasterizer.materialFieldAlphaBytes(...)` 生成固定尺寸材质图，并按画笔设置缓存。
- `SelectionFillRenderer` 在 GPU 中完成材质采样、排列坐标变换、平铺、扰动、覆盖率控制、选区裁切和透明像素锁定。
- 不再使用扇形三角网格，也不沿套索边缘排列笔尖。
- 同一位置连续填充会使用不同 seed；已提交结果仍然是确定的图层像素，可正常撤销和重做。

## 验证重点

- 区域内部应同时存在有效纹理和空隙，不能退化为整块实色。
- 大区域的纹理应分布到内部，而不是只沿轮廓出现。
- 当前画笔与导入素材都应影响结果。
- `排列`、`纹理尺寸`、`覆盖率`、`变化度` 的修改应在下一次填充生效。
- 预览应在切换素材、排列或调整三个滑块时更新，并保持与正式渲染的效果方向一致。
- 锁定透明像素、撤销、重做和图层隔离必须保持正确。
