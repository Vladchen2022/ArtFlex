# 录像工具独立优化与界面验收

日期：2026-09-08。最终构建号：`20260908.8`。
本轮只完成录像工具及验收中阻塞切换工程的打开面板修复。其他优化项目未继续实施。

## 1. 决策摘要

- 仓库复用：沿用现有 `TimelapseRecorderController`、正式 Metal 可见画布合成、GPU 缩小、异步写入队列，以及上一批已经验证的异步文件面板包装。没有新建录屏引擎或 CPU 画布合成器。
- 官方方案：参数持久化使用 UserDefaults；图像使用 ImageIO；视频使用 AVAssetWriter；输出完成后用 FileManager 移动或替换目标；文件选择使用 AppKit 异步附属面板。
- 取舍：重点修复开始/停止、工程隔离、输出完整性和面板可操作性。不新增依赖，不改笔刷盖印、压感和混色公式。

## 2. 实施顺序

1. 备份上轮应用及本轮涉及的六个源文件，保留此前未提交改动。
2. 修复会话生命周期、参数持久化和写入/导出保护。
3. 整理录像弹窗，编译安装后直接操作窗口验收。
4. 对实际失败的打开工程入口和弹窗方向进行修正，重新构建并复测。
5. 恢复录像参数与原画稿，记录边界，到此停止。

## 3. 代码改动

- 捕获间隔、格式、画质、分辨率、自动开始、FPS、开头/结尾停留全部持久化。
- 打开文档或查看面板不再立即创建空录像目录。未命名工程以文档 ID 区分会话，避免不同画稿混用同一目录。
- 文档上下文读取正式 document store，避免打开新工程时使用尚未更新的界面快照名称。
- 开始时立即捕获基准画面；停止时捕获尚未记录的最新变化，不必再等待一个间隔。没有新变化时不重复添加末帧。
- 手动停止会抑制本工程的自动重启；新工程或显式开始仍可正常录制。
- 队列忙时保留待捕获修订并重试；跨会话回调不再错误修改当前会话的计数。待写入帧号预留，避免重复命名。
- 图片先写临时文件，成功完成后才移动到正式帧名；导出视频先写临时文件，确认完成后才替换目标视频。
- 视频导出检查解码、写入器状态、append 结果和超时，不再把部分失败当作成功。只收集 `frame_` 前缀的帧文件。
- 录制及写入期间限制切换输出目录，录制/写入完成后才允许导出；退出时先收尾，仍有写入或导出时阻止立即退出。
- 录像面板固定标题与操作区，中间设置可滚动；限制高度、从入口上方展开，明确深色配色；PNG 下禁用无意义的画质设置。
- 工程打开复用异步文件面板，防止重复发起打开操作。

### 验收中发现后修正的问题

- `.5` 版本按打开工程时发生真实崩溃，栈指向原有 `NSSavePanel.runModal` 路径及系统远程面板生命周期。改为仓库已有异步方式后，`.6` 和 `.8` 重复打开通过。不能由此推断系统中所有其他同步面板都已修复。
- 弹窗第一次侧向展开仍有截断；第二次误将 `.bottom` 当成弹窗自身的边，导致向下展开。查阅 Apple 的 attachment anchor 说明后，最终 `.top` 版本通过当前窗口的可视检查。未将前两次失败算作通过。

## 7. 用户手测清单

请在新建测试画稿或工程副本上操作，不用原稿进行验收。

1. 打开录像工具，确认弹窗内能看见开始、停止、导出；点击开始，应立即得到第一帧。
2. 把间隔设为 10 秒，画一笔后马上停止；待写入变为 0 后，打开最后一帧，确认刚才的笔触存在。
3. 开启自动开始并录制，手动停止后继续画，确认本工程不会自行重新开始。再点击开始应可继续。
4. 分别新建两份未保存画稿进行录制，确认“当前会话”不同、帧不混入另一份画稿。
5. 更改格式、分辨率和 FPS，正常退出后重新打开，确认设置保留；导出并播放视频，检查颜色、蒙版和末帧。
6. 再导出到同名视频，确认替换后能播放；打开已有工程再查看录像，原会话帧数应保留。
