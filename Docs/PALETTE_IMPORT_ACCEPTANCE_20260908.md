# 图片色板导入优化与界面验收

日期：2026-09-08。最终构建号：`20260908.10`。
本轮只处理从图片提取色板及相关面板可操作性；其他模块等待用户确认后再继续。

## 1. 决策摘要

- 仓库复用：保留现有颜色聚类与色板布局，复用 `WorkCancellation`、异步文件面板包装以及参考图模块的 ImageIO 缩略解码用法。不沿用参考图模块的全尺寸解码回退。
- 官方方案：用 ImageIO 直接请求最大边 220 像素的缩略图；后台串行队列完成解码、采样和聚类。用 AppKit 异步附属文件面板选择图片。
- 取舍：不新增依赖，不改画笔、压感、画布合成或主面板分工。图片色板默认保留提取颜色，用户调整滑块后才改变颜色。

## 2. 实施顺序

1. 备份上一版应用与本轮涉及的六个源文件，保留此前未提交修改。
2. 把图片读取、限尺寸采样和聚类接入同一异步请求生命周期。
3. 修正透明像素处理、图片色板默认颜色变换，加入进度、取消和失败提示。
4. 构建安装，直接在软件界面导入测试图片、调整色板并绘画。
5. 修正界面验收发现的色板被压扁问题，重新构建 `.10` 后复测。
6. 保存独立测试画稿，重新打开原画稿，核对原文件未变后停止。

## 3. 代码改动

- 文件、剪贴板和拖放入口统一交给图片提取服务；避免入口先构造整张 NSImage 再转 TIFF。
- 后台串行解码避免多个快速导入同时展开图片；自己的采样缓冲区不超过 220×220，最多采样 12,000 个像素，不再提供全尺寸回退。
- 请求身份、取消信号和文档身份共同限制结果应用；较旧请求不应覆盖较新请求或另一文档的状态。切换色板模式、刷新、重置、同步当前颜色或替换文档时取消待处理请求。
- 解码统一到 sRGB、RGBA 预乘透明度数据；采样时恢复非预乘 RGB，忽略接近全透明的像素，取消原先的铺白处理。
- 单个可见像素也允许生成色板；全透明和无法解码的图片明确提示失败，保留原色板。
- 过滤占比低于 0.5% 的聚类中心，减少缩放边缘杂色；少于 25 个代表色时由去重后的颜色填充现有 25 格。
- 图片色板的默认明度、饱和度和对比度为中性值，不再自动抬高黑色、压暗白色或改变饱和度。其他随机色板的公式不变。
- 修正色板排序对固定 25 个输入的假设，允许较短列表，也不截断较长列表。
- 色板显示来源名称、提取中状态、取消和可关闭错误提示；色块提供十六进制颜色提示。
- 展开高级颜色参数时保留色板最小高度，参数单独滚动，防止色板被挤成无法点击的细线。
- 提取本身不改变当前画笔颜色、不向画布导入图片；点选色块才用于绘画。

## 7. 用户手测清单

建议打开上述测试副本操作。

1. 将颜色面板切到色块模式、展开参数，点击“从图片提取色块”。选择 `01-黑白红绿蓝.png`，确认能看到黑、白、红、绿、蓝；点一个颜色并绘画，检查是否一致。
2. 导入 `02-透明底青色.png`，应只有青色。再分别导入 `03-全透明.png` 和 `05-损坏图片.png`，应提示失败并保留青色色板。
3. 调整明度后点击重置，确认默认颜色回来；展开、滚动参数时，色板不能变成细线，底部参数应可操作。
4. 从 Finder 复制图片，在颜色区粘贴；再把图片直接拖入颜色区。粘贴已测，拖放仍需要补充验证。
5. 导入大图。如果能看到“提取中”，立即点取消，确认稍后旧结果不会重新覆盖原色板。也可导入后立即切换色板模式或开始另一张图片，检查最后结果归属。这些竞争交互尚未在本轮界面上验证。
6. 选择 `07-JPEG画稿.jpg` 和 `08-五级灰阶.png`，确认黑白和灰阶没有被自动染色；取消文件选择应保留原色板。

## 8. 风险与未覆盖项

- 当前 ImageIO 解码调用不能被取消信号立即中断；取消会阻止后续处理和结果应用，下一项排队解码可能仍要等当前调用返回。
- 限制的是本程序取得的缩略图与采样缓冲区，不能据此保证所有格式的 ImageIO 内部解码内存都相同或恒定。
- 未完成拖放、处理中取消和连续请求竞争的 GUI 验收。TIFF、HEIC、BMP、GIF 虽在面板支持列表中，本轮只测试了 PNG 和 JPEG。动画按第一帧提取。
- 没有性能前后基准、内存峰值记录、长时间压力测试或磁盘/内存故障注入，不能宣称获得某个倍数的性能提升或绝无崩溃。
- 代表色来自缩略图与聚类，不是原图完整颜色列表。近透明像素（alpha 小于 16/255）和低占比聚类中心（低于 0.5%）被忽略，细小点缀色可能不出现。
- 既有图片来源色板应用改进后的参数公式，相同非中性参数可能比旧版显示不同；普通随机色板、画笔绘制公式与已保存画稿像素不变。
- 布局验收只覆盖当前窗口，没有宣称所有极小窗口和缩放设置均已通过。
- 本轮到此停止，下一模块等待用户确认。
